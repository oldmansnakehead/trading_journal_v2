# 3. Multi-Tab Journal Entry Management

## Status

Accepted

## Context

ในการใช้งานจริง นักเทรดมักทำการเปิดออเดอร์หลายรายการพร้อมกันในหนึ่งช่วงเวลา (เช่น เทรด 2-3 Setup บนหลายคู่เงินใน London หรือ New York Session เดียวกัน) รูปแบบเดิมของหน้า `JournalEntryForm` มีฟอร์มเดียวและเก็บ State ไว้ภายในคอมโพเนนต์แบบ Local ref ส่งผลให้:
1. ผู้ใช้ต้องกรอกข้อมูล บันทึกทีละรายการ และเริ่มกรอกใหม่ ทำให้เสียเวลาเมื่อมีหลายไม้ในเซสชันเดียวกัน
2. หากสลับหน้าชั่วคราว (เช่น แวะไปดูปฏิทินใน Calendar หรือดูประวัติเดิมใน Dashboard) ข้อมูลที่กรอกค้างไว้จะสูญหาย (Unmounted Form State Loss)
3. ไม่สามารถเปรียบเทียบหรือคัดลอกค่าทั่วไป (เช่น วันเวลา, Timeframe, Session) ไปยังอีก Setup ได้ทันที

## Decision

เราตัดสินใจปรับปรุงระบบบันทึกการเทรดให้รองรับ Multi-Tab ผ่าน Pinia Store (`tradeTabs.ts`):
1. **Pinia Centralized Tab State:**
   - เก็บรายการแท็บ (`tabs`) และแท็บที่กำลังเลือก (`activeTabId`) ไว้ใน Pinia Store
   - ข้อมูล Draft ของทุกแท็บจะคงอยู่ตลอดอายุการรันแอปพลิเคชัน แม้ผู้ใช้จะสลับไปหน้าอื่นแล้วกลับมา
2. **Tab Isolation:**
   - แต่ละแท็บมี State แยกอิสระ 100% รวมถึง `form`, `imageUrls`, `customColumns`, `customData`, และ `setupSessions` เนื่องจากแต่ละ Setup มี Custom Columns และเวลา Session ที่แตกต่างกัน
3. **Tab Capabilities & UX:**
   - **Smart Title:** แสดงชื่อแท็บอัตโนมัติตาม Symbol และ Setup ที่เลือก (เช่น `XAUUSD • Breakout`)
   - **Duplicate Tab:** คัดลอกข้อมูลในแท็บปัจจุบันเพื่อสร้างแท็บใหม่ ช่วยลดเวลาการกรอกข้อมูลซ้ำซ้อน
   - **Save All (Batch Save):** รองรับการบันทึกทุกแท็บที่มีข้อมูลพร้อมกันในคลิกเดียว พร้อมแจ้งสรุปผลลัพธ์
   - **Unsaved Data Protection:** มี Modal เตือนยืนยันก่อนปิดแท็บที่มีข้อมูลอยู่ เพื่อป้องกันการสูญเสียข้อมูลโดยไม่ตั้งใจ
   - **Saved Indicator:** แสดงสถานะบันทึกสำเร็จ (Green check badge) แยกตามแท็บ

## Consequences

- **ข้อดี:**
  - เพิ่มความคล่องตัวในการบันทึกข้อมูลอย่างมาก (High Productivity for multi-setup traders)
  - ป้องกันการสูญหายของข้อมูลร่างระหว่างการสลับหน้า
  - โค้ดมีการแยก Business Logic ออกจาก UI Component อย่างชัดเจนผ่าน Pinia Store
- **ข้อเสีย:**
  - เพิ่มความซับซ้อนในการจัดการหน่วยความจำของ Store เล็กน้อย ซึ่งแก้ไขได้โดยการเคลียร์/รีเซ็ตเมื่อบันทึกเสร็จ
